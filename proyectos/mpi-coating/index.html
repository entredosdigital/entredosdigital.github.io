Nueva web de MPI Coating

MPI Coating es un fabricante de pinturas industriales de Mengíbar (Jaén) con zona comercial en España y Portugal. Renovamos su web, mpicoating.es, para que se viera actual y fuera fácil encontrar sus productos.

El proyecto

  • El punto de partida

    La web anterior se veía anticuada, costaba encontrar los productos y no estaba pensada para el móvil.

  • Diseño nuevo

    Una imagen actual y propia, más rápida y coherente con la marca.

  • Catálogo con buscador

    138 productos ordenados en 13 familias, con buscador y fichas técnicas.

  • Su novedad, destacada

    Una sección propia para el termoplástico preformado.

  • Pensada para el móvil

    Toda la web adaptada a la pantalla del teléfono, desde donde llega la mayoría de visitas.
